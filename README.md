# Geography Explorer

An interactive geography quiz app designed for students in grades 1 through 5. Built with React.

## Features

- **Grade selection** from 1st to 5th grade with age appropriate questions
- **200+ questions** across 20 topic categories covering animals, landforms, capitals, landmarks, U.S. states, climate zones, map skills, and more
- **Fun facts** after every answer to reinforce learning
- **Points and ranking system** from Geography Newbie to World Champion
- **Streak tracking** to reward consecutive correct answers
- **Randomized quizzes** so every playthrough feels fresh

## Grade Levels

| Grade | Topics |
|-------|--------|
| 1st | Animals and Homes, Land and Water, Weather and Seasons, Maps and Directions |
| 2nd | Continents, Oceans and Water, U.S.A. Basics, World Places |
| 3rd | World Capitals, Landforms, Countries, Climate Zones |
| 4th | U.S. States, U.S. Regions, World Geography, Map Skills |
| 5th | Capital Cities, Famous Landmarks, Continents and Oceans, U.S. States |

## Getting Started

```bash
npm install
npm run dev
```
